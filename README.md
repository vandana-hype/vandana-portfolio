# Vandana Kumari — Portfolio

A responsive personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Download and extract the ZIP.
2. Open the `vandana-portfolio` folder.
3. Double-click `index.html` or use the VS Code Live Server extension.

## Publish using GitHub Pages
1. Sign in to GitHub and create a **new public repository** named `vandana-portfolio` (or any name you prefer).
2. Extract this project ZIP on your computer.
3. Open PowerShell / Terminal inside the extracted `vandana-portfolio` folder.
4. Run:

```bash
git init
git add .
git commit -m "Add personal portfolio website"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/vandana-portfolio.git
git push -u origin main
```

Replace `YOUR-USERNAME` with your GitHub username. If GitHub says the remote repository already contains a README, create an empty repository or pull/reconcile the remote before pushing.

5. On GitHub, open the repository → **Settings** → **Pages**.
6. Under **Build and deployment**, select **Deploy from a branch**.
7. Select branch **main**, folder **/(root)**, then click **Save**.
8. Wait for GitHub Pages to publish. Your site URL will be:
   `https://YOUR-USERNAME.github.io/vandana-portfolio/`
